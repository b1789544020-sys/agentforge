# 项目介绍

一个本地就能跑起来的大模型智能体工作台。打开网页就能编辑智能体——选工具、写规则、调参数——点一下跑起来,看着它一步一步地思考、调了哪些工具、产生了什么输出。也能一次出整套试卷批量评测,自动打分。

代码全部跑在本地,不依赖任何云服务。

## 一句话总结

AgentForge 把"设计智能体、跑任务看过程、批量评测打分"这三件事,塞进了一个能装进口袋的本地工作台里。

## 为什么要做这个

市面上的大模型智能体框架大多要么太大(LangChain 那一套,文档看不完),要么太黑盒(跑起来不知道里头在干嘛)。这个项目想做的事很简单:

- **让智能体的每一步都看得见**。不是看日志,是看界面上亮着的一步步:这一步模型想了什么、调了哪个工具、参数是什么、返回值长什么样
- **让工具和规则可以热改**。工具的描述、风险等级、开关状态都存数据库,改完下一步立刻生效,不用重启服务
- **让评测和开发用同一套代码**。批量跑题、自动打分、热图看哪个智能体在哪类题上翻车,跟单步调试共用一套接口

## 适合谁

- 正在搭智能体后端、想看真实代码而不是教程的工程师
- 想知道"循环里头每一步到底在干嘛"的智能体作者
- 想在本地跑一套完整流程,又不想折腾云服务和复杂部署的人

## 怎么跑起来

一条命令:

```
docker compose up --build
```

然后浏览器打开前端地址,就能看到一个能用的智能体工作台。详细步骤在仓库中文文档里(零基础入门 + 网页点击全程)。

## 技术栈(一句话)

后端是 Python 加一个轻量级网页接口框架,数据库是单个文件就能装的下的小型数据库,前端是常见的网页三大件,编排用容器一键起,纯本地零云依赖。
