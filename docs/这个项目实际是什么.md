# 这个项目实际是什么

这是一个本地就能跑起来的大模型智能体框架。一台电脑、一份代码、一个数据库文件,就能让大模型自己思考、自己调工具、自己把每一步记下来。用一条命令把服务起起来,网页上就能看到智能体怎么一步步把活干完。

## 它能干什么

整个项目主要分这么几块:

- **核心循环**: 每一步让模型决定"下一步调哪个工具、调什么参数",调完把结果喂回去继续想。能暂停、能恢复、能中途取消,所有步骤都写进数据库。
- **十个内置工具**: 一行装饰器注册,既能用也能直接当示例抄
  - 回声工具 — 把原文回传,最基础的桩工具
  - 取时间工具 — 拿当前的协调世界时
  - 计算器 — 算四则运算,带安全检查
  - 表达式求值 — 跑一段程序,三种模式,从只能算加减乘除到带沙箱的完整表达式
  - 发起网络请求 — 发网络请求,任意方式、任意地址
  - 执行命令行 — 跑系统命令,带白名单黑名单
  - 读文件、写文件 — 读文件或写文件,有路径白名单
  - 检索知识库 — 在本地知识库里搜
  - 提交最终答案 — 把最终答案交还用户,顺手把循环结束掉
- **五家大模型接好**: 开放人工智能、人类星、深度求索、通义千问、还有一个模拟模式(就是不用真模型,直接返回固定动作,用来调试和跑测试)。换一家只改环境变量。
- **每一步都看得见**: 跑任务时网页实时刷新;跑完能在面板里翻每一步,工具调用、参数、返回值、耗时一目了然。执行命令、发起网络请求这种高风险工具还会带颜色徽标警告。
- **暂停、恢复、取消**: 跑到一半想插一嘴,可以暂停、改上下文、接着跑。不用整轮重来。
- **长期记忆**: 跨任务存事实和偏好,下次开新任务时自动捞回来。
- **批量评测**: 把测试题打包成逐行格式或逗号分隔格式上传,自动并发跑,自动打分,跑完画个热图看哪个智能体在哪类题上翻车。
- **工具元数据存数据库**: 工具的描述、风险等级、开关状态都存在表里,改完不用重启服务、不用改代码。
- **插件式注册**: 新工具或新评分器写一个函数,加一行装饰器就接入,不用改主流程。
- **过程导出**: 跑完一轮能把全过程导出成结构化文本,方便后处理或留档。

## 它对谁有用、有什么用

如果你想搞懂一个大模型智能体到底在背后做了什么、想自己动手改循环里的某个环节,而不是被框架遮住眼睛 — 这套代码就是给你看的。

智能体框架里有几件事是"必须自己实现的、大框架不教你的脏活":怎么把每一步稳稳落库、怎么暂停之后从正确的地方接上、怎么让用户看得见每一步在干嘛、怎么让工具的风险级别在界面上标出来。这些细节这套代码都有真实实现,而不是文档里一句"已支持"。

代码总量不大、模块切分清楚,读核心循环文件一千多行就能看到教科书级别的实现,带暂停恢复、过程记录、风险标注;读工具文件能看到插件式注册器和工具元数据怎么存;读控制文件能看到暂停恢复的状态机。改一处跑一条构建命令立刻看效果。

适合正在搭智能体后端、想看真实代码而不是教程的工程师。也适合拿这个当起点,在它上面加自己的私有工具、内部知识库、定制评分器。
